What is Tailwind CSS?

❌ Traditional CSS

.card { background: white; padding: 1.5rem; border-radius: 0.5rem; box-shadow: 0 4px 6px rgba(0,0,0,0.1); } .card-title { font-size: 1.25rem; font-weight: bold; color: #1f2937; }

✅ Tailwind CSS

<div class="bg-white p-6 rounded-lg shadow-md"> <h2 class="text-xl font-bold text-gray-800"> Title </h2> </div>

Main advantages:

  • ⚡ Fast development: Styles directly in HTML without switching files
  • 🎯 Consistency: Integrated design system with predefined spacing and colors
  • 🎨 Customization: Fully configurable via tailwind.config.js
  • 📦 Optimized size: Only includes classes you use in production

Example: Modern Button

Step by step:

  2. 2. Spacing: py-3 px-6
  3. 3. Corners: rounded-lg
  4. 4. Shadow: shadow
  5. 5. Hover: hover:bg-blue-700
  6. 6. Transition: transition duration-300
  7. 7. Typography: font-semibold

Complete Code:
